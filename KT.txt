# CloudNativeEcommerce – Quick KT (Project Recap)

## 1. Project Overview

CloudNativeEcommerce is a microservices-based application built using .NET 8 and deployed using Docker and Kubernetes.

### Services

* IdentityService (.NET + SQL Server + JWT)
* ProductService (.NET + MongoDB)
* OrderService (.NET + RabbitMQ Producer)
* API Gateway (YARP Reverse Proxy)

Infrastructure:

* SQL Server
* MongoDB
* RabbitMQ
* Seq (Logging)

# 12. Kubernetes Resources

## Namespace

Purpose

Logical isolation.

Example

```
cloudnativeecommerce
```

---

## Pod

Runs the application container.

Example

```
identityservice pod
```

Pods are disposable.

---

## Deployment

Creates Pods.

Maintains desired replicas.

Handles updates.

Example

```
IdentityService Deployment

↓

IdentityService Pod
```

---

## Service

Provides stable networking.

Instead of connecting to

```
10.1.0.25
```

Services connect using

```
sqlserver

mongodb

rabbitmq

identityservice
```

Pods may change.

Service names never change.

---

## ClusterIP

Internal communication only.

Example

```
IdentityService

↓

sqlserver

↓

1433
```

Cannot be accessed directly from browser.

---

## NodePort

Exposes service outside cluster.

Example

```
localhost:30080
```

We mainly used

```
kubectl port-forward
```

during development.

---

## Ingress

Single entry point into cluster.

Example

```
Internet

↓

Ingress

↓

API Gateway
```

Later replaces NodePorts.

---

## ConfigMap

Stores non-sensitive configuration.

Examples

```
Issuer

Audience

Database Name

RabbitMQ Host
```

Injected into container as environment variables.

---

## Secret

Stores sensitive configuration.

Examples

```
JWT Key

SQL Password

Connection String

RabbitMQ Password
```

Never commit secrets to Git.

# 16. Common Issues We Faced

### SQL Login Failed

Cause

```
Database didn't exist
```

Solution

```
Database.Migrate()

Rebuild Docker Image

Redeploy
```

---

### Image Not Updating

Cause

```
Old Docker image
```

Solution

```
docker build

kubectl rollout restart
```

---

### Connection Refused

Cause

```
Port Forward stopped
```

Solution

```
kubectl port-forward
```

---

### Kubernetes Couldn't Start

Solution

```
Reset Kubernetes Cluster

Enable Kubernetes again

Verify:

kubectl get nodes
```
